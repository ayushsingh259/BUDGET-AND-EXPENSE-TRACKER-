# Problem Statement

Students and individuals often spend money on food, transport, shopping, and other daily needs without maintaining a clear record. Manual memory-based tracking makes it difficult to know total spending, remaining balance, or whether a monthly limit has been exceeded.

# Scope

ExpenseTrack is a local console application for recording income and expenses, viewing and searching transactions, deleting incorrect transactions, setting one monthly budget, and generating a simple spending summary. It uses text files for local persistence. It does not provide user accounts, online synchronization, database storage, graphical screens, or financial advice.

# Target Users

The target users are students and individuals who want a simple personal spending record that works from a terminal without installation of external software.

# High-Level Features

- Add income and expense transactions.
- View, search, and delete transactions.
- Validate amounts, text fields, and dates.
- Set and view a monthly budget.
- Calculate income, expenses, balance, category totals, and budget warnings.
- Save data locally between program runs.
